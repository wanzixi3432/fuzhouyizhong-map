# 云端回忆功能配置

`cloud-config.js` 已经连接现有 Supabase 项目。还需要运行一次数据库脚本，创建独立于“南大人的美食地图”的匿名回忆数据表与图片存储桶。

## 操作步骤

1. 打开 Supabase Dashboard。
2. 进入 SQL Editor。
3. 新建查询并清空旧内容。
4. 完整粘贴并运行 `supabase-setup.sql`。
5. 回到网站刷新，无需登录即可发布匿名回忆。

运行脚本后应创建：

```text
表：fuzhou_one_memories
存储桶：fuzhou-memory-images
```

## 权限规则

- 所有访客可以读取匿名回忆。
- 所有访客可以新增匿名回忆。
- 页面不保存发布者账号或姓名。
- 普通用户不能修改或删除别人发布的回忆。
- 新照片只能上传到 `anonymous/` 公共目录。

## 手机访问排查

页面不依赖第三方地图脚本，图片、样式和程序都随网站加载。如果荣耀手机能够打开地图，但发布时报网络错误：

1. 使用荣耀手机自带浏览器或 Chrome 打开，避免使用微信内置浏览器。
2. 检查手机是否能访问 `supabase.co`。
3. 切换 Wi-Fi 与移动数据后重试。
4. 点击详情面板中的“重新检测云端”。

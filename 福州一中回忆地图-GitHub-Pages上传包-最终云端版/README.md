# 福州一中回忆地图

基于福州一中校园卫星平面图制作的共享校园回忆网站。无需登录或注册，任何人都可以在对应地点匿名发表回忆、感想和照片，也可以查看其他人留下的内容。

## 页面功能

- 34 个校园地点：教学楼、宿舍、食堂、运动场、凤池、图书馆、钟楼、实验楼以及体育馆内部四个分支等。
- 卫星地图支持拖动、双指缩放、放大按钮和复位按钮。
- 地点搜索、学习/运动/生活/地标分类和回忆数量显示。
- 完全匿名发布，不显示姓名、邮箱或其他账号信息。
- 每个地点可以发布多段匿名回忆。
- 每条回忆支持最多 6 张照片，较大的手机原图会自动压缩。
- 所有访客都可以查看已发布的文字和照片。
- 页面不包含店铺评分或平台评分。
- 不使用第三方地图脚本，适合荣耀手机等 Android 系统浏览器加载。

## Supabase 初始化

1. 打开现有 Supabase 项目的 SQL Editor。
2. 完整运行 `supabase-setup.sql`。
3. `cloud-config.js` 已经填写项目 URL 和公开密钥。

脚本会创建：

- `fuzhou_one_memories` 回忆数据表
- `fuzhou-memory-images` 图片存储桶
- 匿名读取和匿名新增权限

## 本地打开

直接打开 `index.html` 即可浏览。匿名发布和跨设备回忆同步需要联网。

如果浏览器限制本地文件上传，可以使用静态服务器：

```powershell
node ../static-server.mjs
```

## GitHub Pages

使用 `index.html`、`README.md`、`SUPABASE-SETUP.md` 和平铺资源版本，或将单文件版重命名为 `index.html`。

单文件版已经内联校园地图、CSS、JavaScript 和云端配置，不需要额外的资源文件夹。

## 数据说明

校园图片由用户提供。地点位置根据图片中的已有名称和建筑位置标注；如果后续学校布局或名称发生变化，可以在 `app.js` 顶部的 `PLACES` 数组中调整名称、分类和坐标。
